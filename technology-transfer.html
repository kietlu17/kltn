Cơ sở dữ liệu

MongoDB Document DB

  • auth-service: collection AuthUser gồm email, password hash, role, shopId, trạng thái khóa.
  • user-service: collection UserProfile gồm hồ sơ, số điện thoại và danh sách địa chỉ.
  • shop-service: collection Shop gồm tên shop, ownerId, mô tả.
  • product-service: collections Product, Category gồm sản phẩm, biến thể, ảnh, tồn kho ban đầu và trạng thái duyệt.
  • cart-service: collection Cart gồm userId và danh sách sản phẩm trong giỏ.
  • review-service: collection Review gồm productId, userId, rating, comment.
  • chat-service: collections Conversation, Message cho hội thoại và tin nhắn.

PostgreSQL Relational DB

  • order_service: bảng orders lưu sản phẩm JSONB, tổng tiền, trạng thái, idempotency key, địa chỉ giao hàng, payment method.
  • order_service: bảng disputes lưu khiếu nại, trạng thái xử lý, ghi chú admin.
  • inventory_service: bảng inventory lưu product_id, stock, reserved_stock.
  • payment_service: bảng wallets, wallet_transactions, sepay_payment_requests, sepay_webhook_logs.

HƯỚNG DẪN VÀ CÀI ĐẶT HỆ THỐNG

Có hai cách chạy hệ thống: chạy toàn bộ stack bằng Docker Compose hoặc chạy từng service bằng Node.js. Docker Compose là cách khuyến nghị vì đã cấu hình sẵn MongoDB, PostgreSQL, Kafka, TLS/mTLS và gateway.

Yêu cầu hệ thống

Runtime

  • Node.js 20 trở lên
  • npm đi kèm Node.js
  • Trình duyệt hiện đại để chạy frontend

Container

  • Docker Desktop hoặc Docker Engine
  • Docker Compose v2
  • Tối thiểu 4 GB RAM trống cho stack local

Cổng local

  • 3000 API Gateway
  • 5173 Vite frontend
  • 27017, 5432, 9092, 8080, 4040

Cấu hình môi trường (.env)

Không commit token thật, webhook secret hoặc thông tin tài khoản ngân hàng sản xuất. Dưới đây là mẫu cấu hình an toàn để bàn giao; khi triển khai thực tế cần thay các placeholder bằng giá trị của môi trường đích.

Root .env

NGROK_AUTHTOKEN=<your-ngrok-authtoken>

frontend/.env

VITE_API_GATEWAY_URL=http://localhost:3000
VITE_API_BASE_URL=http://localhost:3000

payment-service/.env

PORT=3010

# PostgreSQL
PG_HOST=postgres
PG_PORT=5432
PG_DATABASE=payment_service
PG_USER=postgres
PG_PASSWORD=<postgres-password>

# Kafka
KAFKA_BROKER=kafka-e:29092

# Wallet
WALLET_DEFAULT_BALANCE=0

# SePay
SEPAY_ENABLED=true
SEPAY_BANK_CODE=<bank-code>
SEPAY_ACCOUNT_NUMBER=<account-number>
SEPAY_ACCOUNT_NAME=<account-name>
SEPAY_WEBHOOK_API_KEY=<webhook-api-key>
SEPAY_QR_BASE_URL=https://qr.sepay.vn/img

# Bank-transfer simulation
BANK_TRANSFER_SHOULD_FAIL=false
BANK_TRANSFER_SHOULD_TIMEOUT=false
BANK_TRANSFER_DELAY_MS=3000
BANK_TRANSFER_TIMEOUT_MS=10000
BANK_TRANSFER_PAYMENT_WINDOW_MS=300000

# TLS / mTLS
TLS_ENABLED=true
TLS_REQUEST_CLIENT_CERT=true
TLS_REJECT_UNAUTHORIZED=true
TLS_CA_PATH=/certs/ca/ca.crt
TLS_CERT_PATH=/certs/payment-service/tls.crt
TLS_KEY_PATH=/certs/payment-service/tls.key
Lưu ý bảo mật: các biến như JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD, GEMINI_API_KEY, SEPAY_WEBHOOK_API_KEY nên được cấu hình qua secret manager hoặc file môi trường riêng theo từng môi trường, không ghi trực tiếp vào tài liệu bàn giao.

Khởi chạy Docker Compose

Chạy toàn bộ hệ thống từ thư mục gốc repository:

docker compose up -d --build

Kiểm tra trạng thái container

docker compose ps
docker compose logs -f api-gateway
docker compose logs -f auth-service
docker compose logs -f payment-service

Các endpoint local quan trọng

Thành phần URL Ghi chú

Cài đặt Backend

Khi chạy bằng Docker Compose, backend đã được build tự động. Nếu cần chạy từng service ở môi trường local, cài dependency trong từng thư mục service rồi chạy npm start. 

cd auth-service
npm install
npm start

Lặp lại với các service backend còn lại:

api-gateway
auth-service
user-service
shop-service
product-service
cart-service
order-service
inventory-service
review-service
chat-service
payment-service
Khi chạy service ngoài Docker, cần đổi biến môi trường trỏ về host local, ví dụ MONGO_URI=mongodb://localhost:27017/auth-service, PG_HOST=localhost, KAFKA_BROKER=localhost:9092, đồng thời tắt hoặc cấp đúng chứng chỉ TLS/mTLS nếu không chạy trong mạng Docker.

Cài đặt Frontend

Frontend đặt trong thư mục frontend, sử dụng Vite dev server tại cổng 5173.

cd frontend
npm install
npm run dev

Build bản production:

cd frontend
npm run build
npm run preview

Khởi tạo cơ sở dữ liệu

MongoDB

MongoDB container được khai báo trong docker-compose.yml. Các database MongoDB được tạo tự động khi service đầu tiên ghi dữ liệu thông qua Mongoose. 

docker compose logs -f mongo

PostgreSQL

PostgreSQL sử dụng script docker/db-init/01-create-databases.sql để tạo ba database nghiệp vụ khi volume PostgreSQL được khởi tạo lần đầu. 

CREATE DATABASE order_service;
CREATE DATABASE inventory_service;
CREATE DATABASE payment_service;

Đồng bộ schema PostgreSQL

Các service order-service, inventory-service, payment-service dùng Sequelize và gọi sequelize.sync() khi khởi động để tạo/cập nhật bảng theo model hiện tại.

Reset dữ liệu local khi cần

docker compose down -v
docker compose up -d --build
Lệnh docker compose down -v xóa toàn bộ volume local gồm MongoDB, PostgreSQL, Kafka và dữ liệu upload. Chỉ dùng cho môi trường phát triển hoặc khi đã sao lưu dữ liệu cần thiết.

Checklist nghiệm thu sau cài đặt

  • docker compose ps hiển thị các service backend, MongoDB, PostgreSQL và Kafka đang chạy.
  • http://localhost:3000 truy cập được API Gateway.
  • http://localhost:8080 mở được Kafka UI.
  • Frontend chạy bằng npm run dev và gọi API Gateway thành công.
  • Đăng ký/đăng nhập user, tạo sản phẩm, tạo đơn hàng và thanh toán test không phát sinh lỗi kết nối DB/Kafka.
Tài liệu được tạo cho mục đích chuyển giao nội bộ. Mọi secret trong ví dụ đã được thay bằng placeholder.
