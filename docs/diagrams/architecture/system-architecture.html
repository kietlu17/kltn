Architecture · ecommerce-microservices

Kiến trúc toàn hệ thống

Gọi đồng bộ · HTTPS + mTLS

  • Order điều phối checkout: gọi Inventory, Voucher, Product, User.
  • Cart → Product, Inventory · Review → Order, Product · Auth → User, Shop.
  • Agentic RAG dùng các service làm tool (product, inventory, review, cart, order, voucher, user).

Bất đồng bộ · Saga qua Kafka

order.created → Payment (orchestrator) → wallet.debit.requested → Wallet → wallet.debited → payment.succeeded → Order order.paid. QR đi qua Payment Gateway (qr.payment.*). Outbox/Inbox ở Payment, Wallet, Gateway.

Hạ tầng phụ

certs-init sinh CA nội bộ + cert từng service. kafka-ui :8080, minio-init tạo bucket. Stack chatbot cũ (chatbot-service, CLIP image-embedding) vẫn trong compose nhưng gateway trỏ tới Agentic RAG.

Mỗi service sở hữu database riêng — nhãn trên ô (MONGO / PG) cho biết store của nó.
